# My Todo App

A React + TypeScript reminder/todo app.

## Stack

- [Vite](https://vitejs.dev/) — build tool and dev server
- [React 19](https://react.dev/) — UI framework
- [TypeScript 6](https://www.typescriptlang.org/) — type safety
- [Bootstrap 5](https://getbootstrap.com/) — styling
- Native `fetch` — HTTP requests (no axios)

## Getting Started

```bash
npm install
npm start
```

Opens at **http://localhost:5173** — or use `Shift+Cmd+B` in Cursor for the built-in browser preview.

## Scripts

| Command | Description |
|---|---|
| `npm start` | Start the dev server |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build locally |
